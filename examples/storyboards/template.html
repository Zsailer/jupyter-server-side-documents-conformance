What every story checks

A person is editing. The connection drops and they keep going. When it comes back, their work must still be there. Each story below is a variation: another tab, the server letting go of the notebook, a file changed underneath, an AI agent. You watch what each copy of the notebook holds, step by step.

How to read a story

The windows

  • Tabs are browser tabs with the notebook open. The blue bar marks the active cell; green means someone is typing in it.
  • Server holds a live copy of the notebook for as long as someone has it open.
  • File on disk is the saved notebook.
  • AI agent acts through the server while it holds the notebook, and on the file when it does not.
  • A hatched window is away: offline, closed, or stopped.

The cells

The player

  • Play / pause and the numbered bar: click a step to jump to it.
  • Amber steps (a reconnect, a rebuild, a crash) are over in a moment in real life. The bar does not fill for them: you see what differs, then the result appears at once.
  • Typing is shown as it is typed. Changes made by the system, not by a person, simply appear.
  • Every story also has its steps as plain text.
